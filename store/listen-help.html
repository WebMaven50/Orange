How to Listen to Your Audiobook

Your download is an M4B file — here's the easiest way to play it, whatever you're using.
iPhone & iPad

📱Use BookPlayer (free)

Apple's own Books app can't import audiobook files you download yourself on an iPhone or iPad directly anymore — only ones synced from a Mac. The simplest fix is a free app called BookPlayer: it reads chapters, remembers your place, and supports bookmarks and speed control, all for free.

  1. Install BookPlayer from the App Store (link below).
  2. Download the audiobook file from your order link.
  3. Tap the downloaded file (or the "Download" banner in Safari), choose Share, then Copy to BookPlayer — or open BookPlayer first and tap Import Files.
  4. It'll show up in your library with chapters, bookmarks, and a "resume where you left off" position, ready to go.
Get BookPlayer — App Store
Android

🤖Use BookPlayer (free)

Same app, same features, on Android — free and open source.

  1. Install BookPlayer from Google Play (link below).
  2. Download the audiobook file.
  3. Open it with BookPlayer directly from your Downloads/Files app, or open BookPlayer and import the file.
Get BookPlayer — Google Play
Mac & Windows

💻Use VLC (free) or Apple Books

VLC Media Player is free, works on both Mac and Windows, and opens M4B files immediately with no conversion — just double-click the downloaded file, or drag it into VLC.

On a Mac, you can also add it to Apple's own Books app: open Books, choose File → Add to Library…, and select the downloaded file. From there it'll sync to Books on your iPhone/iPad too, if you'd rather use Apple's own app on mobile.

Get VLC — videolan.org
One More Thing

Where did my download go?

By default, browsers save downloads straight to your computer's Downloads folder without asking. If you'd rather be asked where to save each file (so you can choose the location yourself), that's a setting in your browser, not something we control:

Safari (Mac): Settings → General → "File download location" → "Ask for each download"

Chrome: Settings → Downloads → turn on "Ask where to save each file before downloading"

Safari (iPhone/iPad): Settings app → Safari → Downloads → "Ask" instead of a fixed location
